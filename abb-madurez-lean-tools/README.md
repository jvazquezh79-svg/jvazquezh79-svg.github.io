# Modelo de Madurez Lean Tools · ABB MTY 1.0

**[Abrir la aplicación](https://jvazquezh79-svg.github.io/abb-madurez-lean-tools/)** · [Página principal](https://jvazquezh79-svg.github.io/)

Instrumento de autoevaluación para el curso Lean Tools de ABB Planta MTY 1.0. Cada equipo determina, con evidencia, el nivel de madurez (0–4) de 14 herramientas Lean en su área y convierte la brecha en un roadmap de mejora, con criterios adaptados al entorno de manufactura bajo pedido con ingeniería (ETO).

## Contenido

| Elemento | Detalle |
| --- | --- |
| Herramientas | VSM, 5S, gestión visual, andon y escalamiento, takt y trabajo estandarizado, layout y flujo, pull/kanban/pacemaker, SMED, gestión de restricciones, TPM/OEE, poka-yoke, solución de problemas, gestión diaria y kaizen |
| Criterios | 60 prácticas, 179 criterios por nivel, 29 métricas de ejecución y 31 preguntas de conocimiento |
| Niveles | 0 No implementado · 1 Inicio · 2 Mejora · 3 Consolidación · 4 Liderazgo, alineados con el Modelo Shingo, CMMI y OpEx 5.0 |
| Reglas | Evidencia obligatoria, regla secuencial por práctica (un nivel se habilita solo si el anterior se cumple) y umbral ajustable (80 % por omisión) |
| Salidas | Resultados con radar y mapa de calor, roadmap por criterio, avance inicial vs. final, consolidado por área y reporte ejecutivo en PDF |

## Cómo utilizarlo

1. Abre el [enlace de acceso](https://jvazquezh79-svg.github.io/abb-madurez-lean-tools/) en Edge o Chrome.
2. Pulsa **▶ Demo guiada** para recorrer el llenado con una evaluación de ejemplo.
3. Crea una evaluación por área y momento (inicial, intermedia o final) y sigue los 11 pasos de la barra lateral.
4. Fija el nivel meta de cada herramienta y completa el roadmap.
5. Genera el reporte ejecutivo con **Imprimir / Guardar PDF** (tamaño Carta, márgenes «Ninguno», gráficos de fondo activados).

La interfaz, los criterios, el glosario y el reporte están disponibles en español e inglés (botón **ES / EN**).

## Uso sin conexión y datos

- La aplicación es un solo archivo HTML sin dependencias externas; también puede descargarse y abrirse sin internet.
- Los datos **no se envían a ningún servidor**: se guardan en el `localStorage` del navegador. Usa **Guardar archivo (.json)** para respaldar o compartir.
- Puedes importar el instrumento en Excel ([ABB_MTY1_Modelo_Madurez_Lean_Tools.xlsx](ABB_MTY1_Modelo_Madurez_Lean_Tools.xlsx)); al importar se aplica la regla secuencial.

Paulk et al. (1993), Capability Maturity Model v1.1; Shingo Institute (2020), The Shingo Model v14.0; Breque et al. (2021), Industry 5.0 (Comisión Europea); Jamwal et al.
